# line-cli-skills: สกิล Claude Code สำหรับ LINE และไฟล์สื่อแนบ

[English](README.md) | [繁體中文（台灣）](README.zh-TW.md) | [日本語](README.ja.md) | ภาษาไทย

สกิลสำหรับให้ Claude Code ทำงานกับ**บัญชี LINE ส่วนตัว**และไฟล์สื่อที่มีผู้ส่งมาให้คุณ สถานะ: **v0.1.2 (ซอฟต์แวร์ระยะเริ่มต้น)** การอ่าน การซิงก์/เก็บถาวรในเครื่อง และการส่งข้อความตัวอักษรทดสอบกับของจริงบน Windows แล้ว การประมวลผลสื่อทดสอบกับสื่อสังเคราะห์เท่านั้น การส่งจะล้มเหลวเฉพาะกับบางคนที่ใช้กุญแจ Letter Sealing เวอร์ชันเก่า ดูรายละเอียดที่ [สถานะ](#สถานะ)

## ข้อสงวนสิทธิ์

- **โปรเจกต์ที่ไม่เป็นทางการ** ไม่มีความเกี่ยวข้อง ไม่ได้รับการรับรอง หรือได้รับการสนับสนุนจาก LINE Corporation / LY Corporation "LINE" เป็นเครื่องหมายการค้าของเจ้าของ ใช้ที่นี่เพียงเพื่ออธิบายสิ่งที่ซอฟต์แวร์ทำงานด้วยเท่านั้น
- โปรเจกต์นี้ใช้ไคลเอนต์ [kongesque/line-cli](https://github.com/kongesque/line-cli) ที่**ไม่เป็นทางการ** ซึ่งเชื่อมต่อกับ LINE นอกแอปทางการ **การใช้งานอาจทำให้บัญชี LINE ของคุณเสี่ยงถูกระงับ** ใช้ด้วยความเสี่ยงของตนเอง และควรใช้กับบัญชีที่คุณยอมเสียได้
- แชตที่เก็บถาวรเป็น**การสนทนาส่วนตัว** ให้เก็บไว้นอกรีโปนี้ และ**ห้าม commit หรือเผยแพร่เด็ดขาด**

## มีอะไรในรีโปนี้

ปลั๊กอิน Claude Code อิสระสองตัว:

- **line-cli** - อ่านและค้นหาแชต กลุ่ม และผู้ติดต่อส่วนตัวใน **LINE** ของคุณ ดาวน์โหลดไฟล์แนบ และ (ยืนยันทุกครั้ง) ส่ง ตอบกลับด้วยรีแอ็กชัน หรือยกเลิกข้อความ ผ่านไคลเอนต์ [kongesque/line-cli](https://github.com/kongesque/line-cli)
  - การตั้งค่าครั้งแรกแบบมีคำแนะนำด้วยภาษาธรรมดา: ติดตั้ง `line` ให้เมื่อคุณตกลงแล้ว (รีลีสที่ตรึงเวอร์ชันไว้ ตรวจ checksum แล้ว ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ) จากนั้นพาคุณเข้าสู่ระบบ
  - ออกแบบให้ปลอดภัย: Claude จะแสดงแชต ข้อความที่แน่นอน และการกระทำนั้น แล้วรอให้คุณตอบ "ใช่" การเขียนไปยัง LINE จะไม่ถูกลองซ้ำโดยอัตโนมัติ
  - ชื่อแชตจะถูกแปลงเป็น ID หากชื่อกำกวม Claude จะถามคุณ ไม่เดาเอง
  - คลังเก็บในเครื่อง: `sync.py` บันทึกข้อความของแต่ละแชต (ไฟล์บันทึก `.jsonl` และไฟล์ `.md` ที่อ่านง่าย) ลงโฟลเดอร์ในเครื่องของคุณ และดาวน์โหลดไฟล์แนบใหม่ทันที เพื่อให้ Claude บอกได้ว่ามีอะไรใหม่ และเก็บประวัติตั้งแต่วันที่คุณเริ่มซิงก์ ไม่ใช่แค่ 100 ข้อความล่าสุดของ LINE
  - ใครตอบกลับหรือกดรีแอคชัน: `thread.py` แสดงคำตอบและรีแอคชันของข้อความที่เก็บไว้หนึ่งข้อความ และ `emoji.py` เก็บป้ายกำกับสั้น ๆ ของรีแอคชันอีโมจิ LINE ที่การซิงก์แคชไว้ตัวละหนึ่งครั้ง (ใช้ร่วมทุกแชต)
  - ส่งหลายแชต เก็บถาวรแบบสด และแจ้งเตือน VIP: `broadcast.py` ส่งข้อความเดียวไปหลายแชต (ทดลองก่อน ส่งจริงหลังคุณตอบตกลงเท่านั้น หยุดทันทีที่ส่งไม่สำเร็จครั้งแรก ไม่ลองซ้ำ); `watch.py` เก็บอาร์ไคฟ์ของแชตที่คุณเลือกให้ทันสมัยอยู่เบื้องหลัง (แชตอื่นจะถูกเมิน) ตามให้ทันเมื่อพลาดเหตุการณ์ และแสดงการแจ้งเตือน Windows เมื่อมีข้อความใหม่ในแชต VIP; การซิงก์จะรายงาน `gap` ที่กู้คืนไม่ได้เมื่อมีข้อความเข้ามาเกิน 100 รายการระหว่างซิงก์สองครั้ง
- **media-digest** - แปลงวิดีโอและเสียงเป็นเฟรมสำคัญพร้อมบทถอดเสียงที่มีเวลากำกับ เพื่อให้ Claude อ่านได้ ใช้ได้กับไฟล์ในเครื่องทุกไฟล์ ไม่จำกัดเฉพาะ LINE
  - วิดีโอ: เฟรมสำคัญจากการตรวจจับการเปลี่ยนฉาก (พร้อมเวลา) และบทถอดเสียง รวมเป็นไทม์ไลน์เดียวใน `digest.md`
  - เสียงและข้อความเสียง: บทถอดเสียงพร้อมเวลากำกับ
  - เอนจินถอดเสียงพูดเป็นข้อความเปลี่ยนได้: `faster-whisper` และ `whisper.cpp` ทำงานในเครื่อง บริการที่เข้ากันได้กับ OpenAI (OpenAI, Groq, vLLM, Speaches) หรือโปรแกรมของคุณเอง ใช้ในเครื่องก่อนเสมอ บริการคลาวด์จะถูกใช้ก็ต่อเมื่อคุณตั้งค่าไว้
- รูปภาพและ PDF ไม่ต้องประมวลผลเพิ่ม Claude อ่านได้โดยตรง

`line-cli` ไม่ได้พึ่งพา `media-digest` หากติดตั้งทั้งสองตัว Claude จะใช้ `media-digest` กับวิดีโอและข้อความเสียงของ LINE

### ความต้องการ

- Claude Code และ Python 3.11 ขึ้นไปใน PATH (Windows, macOS หรือ Linux)
- ปลั๊กอิน `line-cli`: โปรแกรม `line` คุณไม่ต้องติดตั้งเอง Claude จะเสนอให้ติดตั้งให้
- ปลั๊กอิน `media-digest` (ไม่บังคับ Claude จะเสนอช่วยติดตั้งแต่ละส่วนเมื่อจำเป็น): `ffmpeg` สำหรับวิดีโอและเสียง, `uv` พร้อมเอนจิน speech-to-text สำหรับบทถอดเสียง (โดยค่าเริ่มต้นเป็นโมเดลในเครื่องขนาดประมาณ 1.6 GB)

## ติดตั้ง

**วิธี A (แนะนำ): พิมพ์ภายใน Claude Code** เปิด Claude Code (แบบเทอร์มินัล หรือแท็บ Code ในแอป Claude บนเดสก์ท็อป) แล้วพิมพ์ในช่องแชทของมันทีละบรรทัด กด Enter หลังแต่ละบรรทัด:

```text
/plugin marketplace add timliudev/line-cli-skills
/plugin install line-cli@line-cli-skills
/plugin install media-digest@line-cli-skills
```

จากนั้นเริ่มเซสชัน Claude Code ใหม่ เพื่อให้ปลั๊กอินโหลด

**วิธี B: จากเทอร์มินัล** หากติดตั้งคำสั่ง `claude` แล้ว ให้เปิด PowerShell, Terminal หรือ bash แล้วรัน:

```bash
claude plugin marketplace add timliudev/line-cli-skills
claude plugin install line-cli@line-cli-skills
claude plugin install media-digest@line-cli-skills
```

**สำคัญ:** บรรทัดที่ขึ้นต้นด้วย `/` **ไม่ใช่**คำสั่งเทอร์มินัล หากพิมพ์ใน PowerShell, Terminal หรือ bash จะขึ้น "'/plugin' is not recognized" ใช้ได้เฉพาะภายใน Claude Code เท่านั้น ในเทอร์มินัลให้ใช้ `claude plugin ...` ของวิธี B

### เริ่มต้นอย่างรวดเร็ว

1. ใน Claude Code ลองพูดเช่น: "ช่วยเช็กข้อความใหม่ในกลุ่ม LINE ชื่อ Family ให้หน่อย"
2. ครั้งแรก Claude จะตรวจหา `line` อธิบายด้วยภาษาธรรมดาว่าจะติดตั้งอะไร และขอให้คุณอนุญาต จากนั้นขอให้คุณเข้าสู่ระบบ: จะเปิดหน้าต่างเทอร์มินัลใหม่ให้คุณสแกน QR code ด้วยโทรศัพท์ **การเข้าสู่ระบบจะทำให้ส่วนขยาย LINE สำหรับ Chrome ออกจากระบบ**
3. หลังจากนั้นถามได้ตามปกติ เช่น อ่านแชต ค้นหาผู้ติดต่อ "วิดีโอที่ Anna ส่งมาเกี่ยวกับอะไร?" (ต้องใช้ `media-digest`) หรือ "ตอบ OK ให้ Anna" การส่ง ตอบกลับด้วยรีแอ็กชัน หรือยกเลิกข้อความ จะถูกยืนยันกับคุณก่อนทุกครั้ง

ดู[คู่มือผู้ใช้](docs/GUIDE.th.md) สำหรับรายละเอียด การตั้งค่า และการแก้ปัญหา

## สถานะ

**v0.1.0 เป็นรีลีสแรก เป็นซอฟต์แวร์ระยะเริ่มต้น** ระดับการทดสอบของแต่ละส่วนมีดังนี้

- **ทดสอบกับของจริงแล้ว** (บัญชี LINE จริง **เฉพาะ Windows**): การติดตั้งแบบมีคำแนะนำ การเข้าสู่ระบบ การแปลงชื่อแชตเป็น ID การซิงก์และเก็บถาวร การดาวน์โหลดไฟล์แนบ และชื่อกลุ่ม
- **macOS และ Linux:** มีเพียงการทดสอบหน่วย (unit test) ยังไม่เคยลองบนเครื่อง macOS หรือ Linux จริง
- **การส่งใช้งานได้** (ตรวจสอบกับของจริงบน Windows ด้วย line-cli v0.4.0: ข้อความตัวอักษรถึงแชตส่วนตัวพร้อมการเข้ารหัสแบบ end-to-end) จะล้มเหลวเฉพาะเมื่อกุญแจ Letter Sealing ของอีกฝ่ายเป็นเวอร์ชันเก่า (LINE ปฏิเสธด้วย TalkException 86 และต้นทางไม่ลดเวอร์ชันแล้วลองใหม่) กรณีนั้นข้อความจะไม่ถูกส่ง Claude จะแจ้งว่า "ยังไม่ได้ส่ง" ให้ส่งจากแอป LINE แทน การตอบกลับ (`--reply-to`) ใช้เส้นทางการส่งเดียวกันแต่ยังไม่ได้ทดสอบแยกกับของจริง ส่วนการรีแอ็กชันและการยกเลิกข้อความทำไว้แล้ว (ยืนยันทุกครั้ง) แต่ยังไม่ได้ทดสอบกับของจริง
- **media-digest:** การดึงเฟรมสำคัญทดสอบกับสื่อสังเคราะห์ที่สร้างด้วย ffmpeg ยังไม่ได้ทดสอบกับการบันทึกจริง ส่วนอะแดปเตอร์ถอดเสียงพูด (faster-whisper, whisper.cpp, ที่เข้ากันได้กับ OpenAI, คำสั่งที่กำหนดเอง) **ยังไม่เคย**รันกับเอนจินหรือบริการจริง unit test ใช้เพียงของจำลอง (fake)
- **Evals:** eval ของปลั๊กอิน 7 รายการ ([docs/EVALS.md](docs/EVALS.md)) รันอย่างละหนึ่งครั้ง (ครั้งละ 3 รอบต่อเคส) และผ่านทั้ง 7 รายการ eval ตรวจการเรียกใช้สกิลและพฤติกรรมถามก่อนเขียน ไม่ได้ตรวจ LINE เอง
- **ข้อจำกัดที่ทราบ:** ถ้า `chats --search` ของต้นทางล้มเหลว การค้นหาด้วยชื่อจะครอบคลุมเฉพาะแชตที่ใช้งานอยู่ (ตารางแก้ปัญหาในคู่มือมีการแก้ไขที่เกี่ยวข้องอีกสองข้อ)
- **ข้อจำกัดที่ทราบ:** ไม่รองรับการแท็ก @ (ต้นทางไม่มีฟีเจอร์นี้) "@ชื่อ" จะถูกส่งเป็นข้อความธรรมดา ไม่ถูกไฮไลต์ และไม่แจ้งเตือนบุคคลนั้น
