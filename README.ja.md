# line-cli-skills：LINEとメディア添付ファイル向けの Claude Code スキル

[English](README.md) | [繁體中文（台灣）](README.zh-TW.md) | 日本語 | [ภาษาไทย](README.th.md)

**個人のLINEアカウント**での作業と、そこに届く写真・動画・音声などのメディアを扱うための Claude Code スキル集です。状況：**v0.1.2（初期段階のソフトウェア）**。トークの閲覧、ローカルへの同期・アーカイブ、テキストメッセージの送信は Windows で実機確認済み、メディア処理は合成メディアでのテストのみです。送信が失敗するのは、Letter Sealing の鍵が古いバージョンの相手に限られます。詳細は[状況](#状況)を参照してください。

## このリポジトリの内容

2つの独立した Claude Code プラグインを含みます。

- **line-cli**：[kongesque/line-cli](https://github.com/kongesque/line-cli) クライアントを通じて、**個人のLINE**のトーク、グループ、連絡先を閲覧・検索し、添付ファイルをダウンロードします。送信、リアクション、送信取消は、毎回明示的な確認を得た場合のみ行います。
  - 初回セットアップを平易な言葉で案内します。同意後に `line` をインストールし（リリース版に固定、チェックサム検証済み、管理者権限不要）、ログインを案内します。
  - 安全設計：送信、リアクション、送信取消の前に、Claude がトーク、正確な本文、操作内容を示し、「はい」を待ちます。書き込み操作は自動で再試行しません。
  - トーク名はIDに変換します。曖昧な名前は推測せず、あなたに確認します。
  - ローカルアーカイブ：`sync.py` が各トークのメッセージ（`.jsonl` の記録と読みやすい `.md`）をお使いの PC 内のフォルダに保存し、新しい添付ファイルもすぐにダウンロードします。これにより Claude が新着を伝えられ、LINE の直近100件だけでなく、同期を始めた日からの履歴が残ります。
  - 誰が返信・リアクションしたか：`thread.py` はアーカイブ済みの1件のメッセージへの返信とリアクションを一覧にし、`emoji.py` は同期が1種類につき1回だけ（全トーク共通で）キャッシュする LINE 絵文字リアクションに短いラベルを付けます。
  - 一斉送信・ライブアーカイブ・VIP通知：`broadcast.py` は同じメッセージを複数のチャットへ送ります（まず試行、あなたの「はい」の後にだけ送信、最初の失敗で停止、再試行しません）。`watch.py` はバックグラウンドで、あなたが選んだチャットのアーカイブをリアルタイムに保ち（他のチャットは無視）、取りこぼし後に追い付き、VIPチャットの新着にWindows通知を出します。同期の間に100件を超えて届いた場合、同期は取り戻せない `gap` を報告します。
- **media-digest**：動画と音声を、キーフレームとタイムスタンプ付きの文字起こしに変換し、Claude が読める `digest.md` にまとめます。LINE以外の任意のローカルファイルでも使えます。
  - 動画：シーン検出によるキーフレーム（時刻付き）と文字起こしを、1つの `digest.md` のタイムラインにまとめます。
  - 音声とボイスメッセージ：タイムスタンプ付きの文字起こし。
  - 音声認識（speech-to-text）エンジンは差し替え可能です。ローカルの `faster-whisper` と `whisper.cpp`、OpenAI互換サービス（OpenAI、Groq、vLLM、Speaches）、または独自のプログラムを使えます。ローカルを優先し、クラウドサービスは設定した場合のみ使われます。
- 画像とPDFは処理不要で、Claude が直接読み取ります。

`line-cli` は `media-digest` に依存しません。両方をインストールしている場合、LINEの動画やボイスメッセージには Claude が `media-digest` を使います。

### 必要環境

- Claude Code と、PATH 上の Python 3.11 以上（Windows、macOS、Linux のいずれでも可）。
- `line-cli` プラグイン：`line` プログラム。手動でインストールする必要はありません。Claude が導入を提案します。
- `media-digest` プラグイン（すべて任意。必要になったときに Claude が各インストールを提案します）：動画と音声に使う `ffmpeg`、文字起こしに使う `uv` と音声認識エンジン（既定ではローカルモデルを約1.6 GBダウンロードします）。

## インストール

**方法 A（推奨）：Claude Code の中で入力する。** Claude Code（ターミナル版、または Claude デスクトップアプリの Code タブ）を開き、チャット欄に 1 行ずつ入力して Enter を押します。

```text
/plugin marketplace add timliudev/line-cli-skills
/plugin install line-cli@line-cli-skills
/plugin install media-digest@line-cli-skills
```

その後、新しい Claude Code セッションを開始するとプラグインが読み込まれます。

**方法 B：ターミナルから。** `claude` コマンドがインストール済みなら、PowerShell・Terminal・bash を開いて実行します。

```bash
claude plugin marketplace add timliudev/line-cli-skills
claude plugin install line-cli@line-cli-skills
claude plugin install media-digest@line-cli-skills
```

**重要：** `/` で始まる行はターミナルのコマンドでは**ありません**。PowerShell・Terminal・bash に入力すると「'/plugin' is not recognized」と表示されます。Claude Code の中でのみ動作します。ターミナルでは方法 B の `claude plugin ...` を使ってください。

### クイックスタート

1. Claude Code で、たとえば「LINEのグループ『Family』に新しいメッセージがないか確認して」と伝えます。
2. 初回は、Claude が `line` の有無を確認し、インストール内容を平易に説明して、実行の許可を求めます。その後、ログインを案内します。新しいターミナルウィンドウが開くので、スマートフォンでQRコードを読み取ってください。**ログインすると LINE の Chrome 拡張機能からはログアウトされます。**
3. それ以降は普段どおり依頼できます。トークを読む、連絡先を探す、「Anna が送ってきた動画は何の話？」（`media-digest` が必要）、「Anna に OK と返信して」など。送信、リアクション、送信取消は、毎回事前に確認します。

詳細、設定、トラブルシューティングは[ユーザーガイド](docs/GUIDE.ja.md)を参照してください。

## 状況

**v0.1.0 は初回リリースで、初期段階のソフトウェアです。** 各部分のテスト状況は次のとおりです。

- **実機で確認済み**（実際の LINE アカウント、**Windows のみ**）：ガイド付きインストール、ログイン、トーク名の解決、同期とアーカイブ、添付ファイルのダウンロード、グループ名。
- **macOS と Linux：** 単体テストのみです。実際の macOS・Linux マシンではまだ試していません。
- **送信は動作します**（Windows・line-cli v0.4.0 で実機確認：1対1トークへのテキストメッセージがエンドツーエンド暗号化で届きました）。失敗するのは、相手の Letter Sealing の鍵が古いバージョンの場合のみです（LINE が TalkException 86 で拒否し、上流はバージョンを下げて再試行しません）。その場合メッセージは送信されず、Claude は「送信されていません」とお伝えしますので、LINE アプリから送ってください。返信（`--reply-to`）は同じ送信経路を使いますが、単独での実機確認はしていません。リアクションと送信取消は実装済み（毎回確認）ですが、実機では未確認です。
- **media-digest：** キーフレーム抽出は ffmpeg で作った合成メディアでテストしたもので、実際の録画ではまだ試していません。音声認識アダプター（faster-whisper、whisper.cpp、OpenAI互換、独自コマンド）は、実際のエンジンやサービスに対して**まだ実行していません**。単体テストはフェイク（模擬）のみを使っています。
- **Evals：** 7 つのプラグイン eval（[docs/EVALS.md](docs/EVALS.md)）を各1回実行し（1ケースにつき3回試行）、7 つすべて合格しました。確認しているのはスキルの起動と書き込み前の確認の挙動であり、LINE 自体ではありません。
- **既知の制限：** 上流の `chats --search` が失敗した場合、名前検索はアクティブなトークのみが対象です（ガイドのトラブルシューティング表に関連する修正がほかに2件あります）。
- **既知の制限：** @メンションには未対応です（上流にメンション機能がありません）。「@名前」は通常のテキストとして送られ、強調表示も通知もされません。

詳しくは[ユーザーガイド](docs/GUIDE.ja.md)と[変更履歴](CHANGELOG.md)を参照してください。
