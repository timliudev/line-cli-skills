# line-cli-skills：LINEとメディア添付ファイル向けの Claude Code スキル

[English](README.md) | [繁體中文（台灣）](README.zh-TW.md) | 日本語 | [ภาษาไทย](README.th.md)

**個人のLINEアカウント**での作業と、そこに届く写真・動画・音声などのメディアを扱うための Claude Code スキル集です。状況：**初期開発段階（v0.0.x）**。トークの閲覧、メッセージの送信、ローカルへの同期・アーカイブ、メディアの処理は動作します。

## このリポジトリの内容

2つの独立した Claude Code プラグインを含みます。

- **line-cli**：[kongesque/line-cli](https://github.com/kongesque/line-cli) クライアントを通じて、**個人のLINE**のトーク、グループ、連絡先を閲覧・検索し、添付ファイルをダウンロードします。送信、リアクション、送信取消は、毎回明示的な確認を得た場合のみ行います。
  - 初回セットアップを平易な言葉で案内します。同意後に `line` をインストールし（リリース版に固定、チェックサム検証済み、管理者権限不要）、ログインを案内します。
  - 安全設計：送信、リアクション、送信取消の前に、Claude がトーク、正確な本文、操作内容を示し、「はい」を待ちます。書き込み操作は自動で再試行しません。
  - トーク名はIDに変換します。曖昧な名前は推測せず、あなたに確認します。
  - ローカルアーカイブ：`sync.py` が各トークのメッセージ（`.jsonl` の記録と読みやすい `.md`）をお使いの PC 内のフォルダに保存し、新しい添付ファイルもすぐにダウンロードします。これにより Claude が新着を伝えられ、LINE の直近100件だけでなく、同期を始めた日からの履歴が残ります。
- **media-digest**：動画と音声を、キーフレームとタイムスタンプ付きの文字起こしに変換し、Claude が読める `digest.md` にまとめます。LINE以外の任意のローカルファイルでも使えます。
  - 動画：シーン検出によるキーフレーム（時刻付き）と文字起こしを、1つの `digest.md` のタイムラインにまとめます。
  - 音声とボイスメッセージ：タイムスタンプ付きの文字起こし。
  - 音声認識（speech-to-text）エンジンは差し替え可能です。ローカルの `faster-whisper` と `whisper.cpp`、OpenAI互換サービス（OpenAI、Groq、vLLM、Speaches）、または独自のプログラムを使えます。ローカルを優先し、クラウドサービスは設定した場合のみ使われます。
- 画像とPDFは処理不要で、Claude が直接読み取ります。

`line-cli` は `media-digest` に依存しません。両方をインストールしている場合、LINEの動画やボイスメッセージには Claude が `media-digest` を使います。

### 必要環境

- Claude Code と、PATH 上の Python 3.11 以上（Windows、macOS、Linux のいずれでも可）。
- `line-cli` プラグイン：`line` プログラム。手動でインストールする必要はありません。Claude が導入を提案します。
- `media-digest` プラグイン（すべて任意。必要になったときに Claude が各インストールを提案します）：動画と音声に使う `ffmpeg`、文字起こしに使う `uv` と音声認識エンジン（既定ではローカルモデルを約1.6 GBダウンロードします）。

## インストール

```
/plugin marketplace add timliudev/line-cli-skills
/plugin install line-cli@line-cli-skills
/plugin install media-digest@line-cli-skills
```

### クイックスタート

1. Claude Code で、たとえば「LINEのグループ『Family』に新しいメッセージがないか確認して」と伝えます。
2. 初回は、Claude が `line` の有無を確認し、インストール内容を平易に説明して、実行の許可を求めます。その後、ログインを案内します。新しいターミナルウィンドウが開くので、スマートフォンでQRコードを読み取ってください。**ログインすると LINE の Chrome 拡張機能からはログアウトされます。**
3. それ以降は普段どおり依頼できます。トークを読む、連絡先を探す、「Anna が送ってきた動画は何の話？」（`media-digest` が必要）、「Anna に OK と返信して」など。送信、リアクション、送信取消は、毎回事前に確認します。

詳細、設定、トラブルシューティングは[ユーザーガイド](docs/GUIDE.ja.md)を参照してください。

## 状況

初期開発段階です。実装済み：ガイド付きのインストールとログイン、トークの閲覧と検索、トーク履歴のローカル同期とアーカイブ（`sync.py`、添付ファイルの自動ダウンロード付き）、確認付きの送信・リアクション・送信取消、メディアの処理と音声認識バックエンド。詳しくは[ユーザーガイド](docs/GUIDE.ja.md)と[変更履歴](CHANGELOG.md)を参照してください。既知の制限：上流の `chats --search` が失敗した場合、名前検索はアクティブなトークのみが対象です（ガイドのトラブルシューティング表に関連する修正がほかに2件あります）。既知の上流バグ：一部の1対1トークへの送信は失敗します（LINE が暗号化バージョンを拒否します）。Claude は「送信されていません」とお伝えしますので、LINE アプリから送ってください。
