## การติดตั้ง

เพิ่ม marketplace และติดตั้งปลั๊กอิน:

```
/plugin marketplace add timliudev/line-cli-skills
/plugin install line-cli@line-cli-skills
/plugin install media-digest@line-cli-skills
```

- `line-cli` สำหรับ LINE `media-digest` เป็นตัวเลือกเพิ่มเติม ใช้ได้กับไฟล์วิดีโอหรือเสียงทุกไฟล์ ติดตั้งหากคุณต้องการให้ Claude เข้าใจวิดีโอและข้อความเสียงของ LINE
- คุณต้องมี Python 3.11 ขึ้นไป หากระบบหา `python` ไม่พบ Claude จะลอง `python3` หรือ `py -3`
- โปรแกรม `line` จาก kongesque/line-cli ติดตั้งแยกต่างหาก คุณไม่ต้องทำเอง: ครั้งแรกที่ใช้ LINE Claude จะอธิบายว่าจะติดตั้งอะไร และถามคุณก่อน (ดูหัวข้อถัดไป)

## การตั้งค่าครั้งแรกและการเข้าสู่ระบบ

เมื่อคุณถามเรื่อง LINE เป็นครั้งแรก Claude จะตรวจสอบและพาคุณผ่านสิ่งที่ยังขาดอยู่ คุณจะถูกถามก่อนทุกขั้นตอน

1. **ติดตั้ง `line`** Claude จะบอกด้วยภาษาธรรมดาว่าจะดาวน์โหลด LINE CLI จากหน้า GitHub ทางการ นำไปไว้ในโฟลเดอร์ผู้ใช้ของคุณ (ไม่ต้องมีสิทธิ์ผู้ดูแลระบบ) และตรวจว่าไฟล์ไม่ถูกแก้ไข จะยังไม่มีอะไรเกิดขึ้นจนกว่าคุณจะตอบว่าใช่
   - Windows: ตัวติดตั้ง PowerShell ทางการ ไปยัง `%LOCALAPPDATA%\line-cli\bin`
   - macOS: Homebrew (`brew install kongesque/tap/line-cli`) หากคุณมี มิฉะนั้นใช้ตัวติดตั้ง shell ทางการ ไปยัง `~/.local/bin`
   - Linux: ตัวติดตั้ง shell ทางการ ไปยัง `~/.local/bin`
   - สคริปต์ตัวติดตั้งและโปรแกรมถูกกำหนดให้เป็นรีลีสเฉพาะที่ทดสอบแล้ว (v0.4.0) และตรวจสอบด้วย checksum (Homebrew จะติดตั้งรีลีสปัจจุบันของ tap จึงตรึงเวอร์ชันไม่ได้) ใช้งานได้ทันทีโดยไม่ต้องเปิดเทอร์มินัลใหม่
   - บนเดสก์ท็อป Linux อาจยังไม่มีแพ็กเกจ system keyring Claude จะแสดงคำสั่ง `sudo` ให้ และคุณเป็นคนรันเอง Claude จะไม่ใช้ `sudo` เด็ดขาด
2. **เข้าสู่ระบบ** Claude จะเตือนก่อน: **การเข้าสู่ระบบจะทำให้คุณออกจากระบบส่วนขยาย LINE สำหรับ Chrome** เพราะ LINE อนุญาตให้มีเซสชันแบบนี้ได้ทีละหนึ่งเซสชัน เมื่อคุณตอบตกลง หน้าต่างเทอร์มินัลใหม่จะเปิดขึ้น สแกน QR code ด้วย LINE บนโทรศัพท์ หรือเข้าสู่ระบบด้วยอีเมลและรหัสผ่านที่พิมพ์ในหน้าต่างนั้น Claude จะไม่เห็นรหัสผ่านของคุณ ระบบจะรอได้สูงสุดห้านาทีและยืนยันด้วยชื่อบัญชีของคุณ หากเปิดหน้าต่างไม่ได้ (เช่น ผ่าน SSH) Claude จะให้คำสั่งเดียวให้คุณรันเอง
3. **เสร็จแล้ว** เซสชันจะถูกเก็บในที่เก็บข้อมูลที่ปลอดภัยของระบบปฏิบัติการ และต่ออายุตัวเองประมาณทุกสัปดาห์ ปกติคุณจึงเข้าสู่ระบบเพียงครั้งเดียว ต้องเข้าสู่ระบบอีกครั้งเฉพาะเมื่อ LINE ทำให้เซสชันออกจากระบบ

ไคลเอนต์ที่ไม่เป็นทางการมีความเสี่ยงต่อบัญชีของคุณ (ดูใน README) การใช้บัญชีสำรองจึงเป็นทางเลือกที่ฉลาด

## การใช้งานประจำวัน

เพียงพิมพ์ถาม เช่น "กลุ่ม Family พูดอะไรวันนี้บ้าง?" หรือ "มีข้อความใหม่จาก Anna ไหม?"

- **ค้นหาแชต** Claude จะค้นชื่อและใช้ ID แชตจริง หากมีหลายแชตตรงกัน (เช่น "Anna" ที่เป็นเพื่อน และ "Anna" ที่เป็นกลุ่ม) Claude จะแสดงรายการและถามว่าต้องการแชตไหน มันไม่เดาเอง
- **การอ่าน** Claude อ่านข้อความล่าสุด (ค่าเริ่มต้น 20 ข้อความ สูงสุดไม่เกิน 100 ข้อความล่าสุดต่อแชต ซึ่งเป็นขีดจำกัดของไคลเอนต์นี้ตามที่ LINE กำหนด) แล้วสรุปเป็นภาษาของคุณ รูปภาพ วิดีโอ ข้อความเสียง และไฟล์จะปรากฏเป็นไฟล์แนบที่คุณขอให้เปิดได้ สติกเกอร์แสดงไม่ได้ การอ่านไม่ทำให้ข้อความถูกทำเครื่องหมายว่าอ่านแล้ว
- **ส่ง ตอบกลับด้วยรีแอ็กชัน และยกเลิก** การกระทำเหล่านี้ไปถึงคนอื่น จึงยืนยันทุกครั้ง Claude จะแสดงชื่อแชต ข้อความที่แน่นอน (หรือข้อความและรีแอ็กชัน) แล้วรอคำว่า "ใช่" ที่ชัดเจน หากคุณเปลี่ยนอะไร Claude จะถามใหม่
  - ข้อความที่ส่งจะถูกส่งตรงตามที่แสดง ไฟล์ขนาดได้ถึง 20 MiB ข้อความยาวได้สูงสุด 10,000 ตัวอักษร
  - Claude ลองหนึ่งครั้งและไม่ลองซ้ำเอง หากการเชื่อมต่อหลุดระหว่างส่ง Claude จะตรวจแชตก่อนว่าข้อความไปถึงหรือยัง แล้วจึงเสนอทางเลือก
  - การยกเลิกจะลบข้อความของคุณเองสำหรับทุกคน และย้อนกลับไม่ได้
- **ข้อความจากผู้อื่นถือเป็นข้อมูล** ไม่ใช่คำสั่ง หากข้อความในแชตพูดว่า "ทำสิ่งนี้" หรือ "ส่งสิ่งนั้นให้ใครสักคน" Claude จะแสดงให้คุณเห็นและถามก่อน
- **คลังเก็บในเครื่อง** ก่อนตอบคำถามเกี่ยวกับแชต Claude จะซิงก์ก่อน: ดึง 100 ข้อความล่าสุด เพิ่มข้อความใหม่ลงโฟลเดอร์ในคอมพิวเตอร์ของคุณ (`messages.jsonl` เป็นบันทึกหลัก ส่วน `messages.md` ไว้อ่าน) และดาวน์โหลดรูปภาพ วิดีโอ ข้อความเสียง และไฟล์ใหม่ทันที เพราะ LINE ทำให้ไฟล์แนบหมดอายุ วิธีนี้ทำให้ตอบคำถาม "มีอะไรใหม่ไหม" ได้เร็ว และเก็บประวัติที่เก่ากว่า 100 ข้อความล่าสุดของ LINE ไว้ได้ตั้งแต่การซิงก์ครั้งแรก คุณสั่งให้ซิงก์โดยตรงได้เช่นกัน ทั้งแชตเดียวหรือ "ทุกแชตของฉัน"
  - ควรรู้: การซิงก์เพียงอ่านจาก LINE การซิงก์ครั้งแรกของแต่ละแชตดึงได้เพียง 100 ข้อความล่าสุด หากระหว่างการซิงก์สองครั้งมีข้อความเข้ามาเกิน 100 ข้อความ Claude จะแจ้งว่ามีช่องว่าง ข้อความที่เก็บไว้แล้วแต่หายไปจาก 100 ข้อความล่าสุดของ LINE จะถูกเก็บไว้และทำเครื่องหมาย "(possibly unsent)" (อาจถูกยกเลิกส่ง) ซึ่งเป็นเพียงการคาดเดา ไม่ใช่ข้อสรุป

## ไฟล์แนบและ media-digest

- **รูปภาพและ PDF** Claude เปิดไฟล์โดยตรงจากโฟลเดอร์คลังเก็บของแชตนั้น (ดาวน์โหลดไว้ตอนซิงก์ ไม่เกิน 20 MiB)
- **วิดีโอ** เมื่อมี `media-digest` Claude จะตัดวิดีโอเป็นเฟรมสำคัญ (ตามการเปลี่ยนฉาก สูงสุด 24 เฟรมโดยค่าเริ่มต้น) และถอดเสียงพูด แล้วอ่านไฟล์ `digest.md` เดียวที่เรียงเฟรมและข้อความตามเวลา
- **ข้อความเสียงและไฟล์เสียง** Claude ถอดเสียงพร้อมเวลากำกับ
- หากไม่มี `media-digest` Claude จะบอกตำแหน่งของไฟล์ และแจ้งว่าการติดตั้งปลั๊กอินจะทำให้เข้าใจวิดีโอและเสียงได้
- บางอย่างอาจขาดหายหรือใช้ไม่ได้: ไฟล์แนบที่ LINE หมดอายุแล้ว ไฟล์ที่เกิน 20 MiB และสื่อที่เก็บอยู่หลังลิงก์ภายนอกไม่สามารถดาวน์โหลดได้
- ระหว่างซิงก์ ไฟล์แนบใหม่จะถูกดาวน์โหลดให้ (ไม่เกิน 20 MiB ต่อไฟล์ ทุกประเภทตามค่าเริ่มต้น) ลงโฟลเดอร์ `files` ของแชตนั้น รูปภาพและ PDF อ่านจากที่นั่นโดยตรง ส่วนวิดีโอและข้อความเสียงจะส่งต่อให้ `media-digest`

สิ่งที่ `media-digest` ต้องใช้ จะเสนอให้เมื่อคุณยินยอม พร้อมระบุขนาดการดาวน์โหลด:

| ต้องการ | เพื่อ | วิธีติดตั้ง |
| --- | --- | --- |
| ffmpeg | เฟรมวิดีโอ การจัดการเสียง | `winget install --id Gyan.FFmpeg -e` (Windows), `brew install ffmpeg` (macOS), `sudo apt install ffmpeg` (Linux, คุณรันเอง) |
| uv | ตัวถอดเสียงในเครื่องค่าเริ่มต้น | winget, brew หรือตัวติดตั้งทางการ |
| เอนจิน speech-to-text | บทถอดเสียง | `faster-whisper` ในเครื่องโดยค่าเริ่มต้น (ติดตั้งเองเมื่อใช้ครั้งแรก โมเดลประมาณ 1.6 GB ดาวน์โหลดครั้งเดียว) ทางเลือกอื่นอยู่ด้านล่าง |

หากไม่มี ffmpeg คุณยังได้รูปภาพและ PDF หากไม่มีเอนจิน speech-to-text คุณยังได้เฟรมสำคัญของวิดีโอ

Claude จะรัน `digest.py FILE... --out OUTDIR` จากโฟลเดอร์ `skills/media-digest/scripts` ของปลั๊กอินให้คุณ ตัวเลือกที่มีประโยชน์: `--lang zh` (ภาษาของเสียงพูด ค่าเริ่มต้นคือตรวจจับอัตโนมัติ), `--max-frames 24`, `--no-asr` (เฉพาะเฟรม), `--force` (ทำใหม่) ผลลัพธ์คือ `OUTDIR/digest.md` และ `digest.json` ผลลัพธ์จะถูกเก็บในแคช และไฟล์ที่ไม่มีบทถอดเสียงจะถูกลองใหม่อัตโนมัติเมื่อติดตั้งเอนจินแล้ว

## การตั้งค่า

ทุกอย่างใช้งานได้โดยไม่ต้องตั้งค่า มีไฟล์ `config.toml` แบบไม่บังคับอยู่สองไฟล์ (แต่ละสกิลบันทึกรายละเอียดไว้ใน `references/`) ความลับจะไม่ถูกเก็บในไฟล์เหล่านี้ เก็บเพียง**ชื่อ**ของตัวแปรสภาพแวดล้อมเท่านั้น

**`line-cli`** (`%APPDATA%\line-skill\config.toml` บน Windows มิฉะนั้นคือ `~/.config/line-skill/config.toml`):

| คีย์ | ความหมาย |
| --- | --- |
| `line_path` | ใช้โปรแกรม `line` ที่ระบุ (เช่น fork หรือบิลด์ที่ตรึงเวอร์ชันไว้) |
| `archive_root` | ตำแหน่งที่เก็บคลัง (ตั้งผ่านตัวแปรสภาพแวดล้อม `LINE_SKILL_ARCHIVE` ได้เช่นกัน และมีลำดับความสำคัญสูงกว่า) ค่าเริ่มต้น: `%LOCALAPPDATA%\line-skill\archive` (Windows), `~/Library/Application Support/line-skill/archive` (macOS), `~/.local/share/line-skill/archive` (Linux) |
| `download.types`, `download.max_bytes` | ประเภทไฟล์แนบที่ดาวน์โหลดอัตโนมัติ (`image`, `video`, `audio`, `file`) และขีดจำกัดขนาดเป็นไบต์ (ค่าเริ่มต้น 20 MiB ซึ่งเป็นค่าสูงสุดที่ไคลเอนต์นี้ดึงได้) |
| `render.quiet_gap_days` | ใน `messages.md` จะแทรกบรรทัด "no messages for X days" เมื่อข้อความสองข้อความติดกันห่างกันเกินจำนวนวันนี้ (ค่าเริ่มต้น 3; `0` คือปิด) |

**`media-digest`** (`%APPDATA%\media-digest\config.toml` บน Windows มิฉะนั้นคือ `~/.config/media-digest/config.toml` เขียนทับได้ด้วย `MEDIA_DIGEST_CONFIG`):

```toml
[asr]
order = ["faster_whisper", "whisper_cpp", "groq"]   # try these in order

[asr.routes]                                          # per speech language
zh = ["faster_whisper", "groq"]

[adapters.groq]                                       # a cloud service, used because it is listed above
preset = "groq"                                       # api_key_env = "GROQ_API_KEY" comes with the preset
```

- เอนจิน: `faster_whisper` (ในเครื่อง ค่าเริ่มต้น), `whisper_cpp` (ในเครื่อง ต้องมี `model_path`), `openai_compat` (preset ของ OpenAI, Groq, vLLM, Speaches หรือ URL ของคุณเอง) และ `command` (โปรแกรมใดก็ได้ที่คุณมี รวมถึงเซิร์ฟเวอร์ของคุณเอง)
- หากไม่มีไฟล์ ระบบจะใช้เฉพาะในเครื่อง เอนจินคลาวด์จะถูกใช้ก็ต่อเมื่อระบุไว้ใน `order` หรือ `routes`
- ส่งออก API key ในเชลล์ที่เปิด Claude Code เช่น `export GROQ_API_KEY=...` และอย่าวางคีย์ลงในแชตเด็ดขาด
- เส้นทางตามภาษาจะมีผลเมื่อคุณระบุภาษา (`--lang zh`) ไม่มีผลเมื่อเป็น `auto`
- เอกสารอ้างอิงฉบับเต็ม: ไฟล์ `references/config.md`, `references/adapters.md` และ `references/install.md` ของปลั๊กอิน `media-digest`

## ความเป็นส่วนตัว

- แชต ไฟล์แนบที่ดาวน์โหลด และ digest ของคุณเป็นการสนทนาส่วนตัว เก็บไว้ในเครื่องของคุณ ไม่เคยอยู่ในโฟลเดอร์ปลั๊กอิน ห้าม commit หรือเผยแพร่ และเก็บให้พ้นจากรีโป git ใดๆ
- คลังเก็บคือโฟลเดอร์บทสนทนาส่วนตัวในเครื่องของคุณ (ค่าเริ่มต้นอยู่ในโปรไฟล์ผู้ใช้ ไม่เคยอยู่ในไดเรกทอรีของปลั๊กอิน) หากตำแหน่งคลังอยู่ในรีโพ git Claude จะเตือน ให้ย้ายออก และห้าม commit หรือเผยแพร่เด็ดขาด
- Claude จะไม่ส่งเนื้อหาแชตไปยังบริการอื่น การถอดเสียงทำในเครื่องเว้นแต่คุณตั้งค่าเอนจินคลาวด์ Claude จะบอกว่าบริการใดจะได้รับเสียง และถามก่อนอัปโหลดครั้งแรก
- Claude จะไม่ขอรหัสผ่าน LINE ของคุณในแชต และไม่อ่านเซสชันที่เก็บไว้
- การส่ง ตอบกลับด้วยรีแอ็กชัน และยกเลิก ต้องได้รับคำว่า "ใช่" อย่างชัดเจนจากคุณทุกครั้ง จะไม่มีการส่งอะไรในเบื้องหลัง
- ข้อความที่คุณอ่านอาจมีคำสั่งที่มุ่งถึง AI Claude จะถือว่าเป็นข้อความ ไม่ใช่คำสั่ง

## การแก้ปัญหา

ลองพิมพ์ให้ Claude ว่า "run the LINE doctor" ระบบจะรัน `setup.py --doctor` จากโฟลเดอร์ `skills/line-cli/scripts` ของปลั๊กอิน ซึ่งตรวจ Python โปรแกรม `line` และเวอร์ชัน การเข้าสู่ระบบ keyring (Linux) ไฟล์ตั้งค่า โฟลเดอร์คลังเก็บเขียนได้หรือไม่ และว่ามีการอัปเดตหรือไม่ พร้อมคำแนะนำเป็นภาษาธรรมดาสำหรับแต่ละรายการ ตรวจผลลัพธ์ก่อนวางในรายงานบั๊ก เพราะอาจมีพาธในเครื่องและชื่อบัญชีของคุณ

| อาการ | ควรทำอย่างไร |
| --- | --- |
| "line not found" | ให้ Claude รันการติดตั้งแบบมีคำแนะนำ หรือตรวจ `line_path` ในไฟล์ตั้งค่า |
| "not logged in" | ขอให้ Claude เข้าสู่ระบบให้ จำไว้ว่าจะทำให้ส่วนขยาย Chrome ออกจากระบบ |
| หน้าต่างเข้าสู่ระบบไม่เปิด | รัน `line login` เองในเทอร์มินัล แล้วขอให้ Claude ตรวจอีกครั้ง |
| Linux: keyring หายไปหรือถูกล็อก | ติดตั้งแพ็กเกจที่ Claude แสดง (`libsecret-tools`, `gnome-keyring`) แล้วปลดล็อก keyring สำหรับเซิร์ฟเวอร์ดูตัวเลือก headless ใน `references/setup.md` |
| "busy" | มีคำสั่ง `line` อื่นกำลังทำงานอยู่ รอสักครู่ (การอ่านจะลองใหม่อัตโนมัติ) |
| วิดีโอมีเฟรมแต่ไม่มีบทถอดเสียง | ยังไม่มีเอนจิน speech-to-text ที่พร้อมใช้งาน ให้ขอให้ Claude แสดงรายการและตั้งค่าให้ |
| "needs ffmpeg" | ติดตั้ง ffmpeg (ดูด้านบน) แล้วรันอีกครั้ง |
| การถอดเสียงไฟล์ยาวด้วยบริการคลาวด์ล้มเหลว | ยังไม่รองรับการแบ่งไฟล์เสียงที่เกิน 25 MB ให้ใช้เอนจินในเครื่องแทน |
| ข้อความอาจยังไม่ถูกส่ง | Claude จะตรวจแชตก่อน และจะไม่ส่งซ้ำโดยไม่ได้รับคำว่าใช่จากคุณ |
| Claude เตือนว่ามี "ช่องว่าง" | ตั้งแต่การซิงก์ครั้งก่อนมีข้อความเข้ามาเกิน 100 ข้อความ ส่วนที่ขาดกู้คืนไม่ได้ ควรซิงก์ให้ถี่ขึ้น |
| ข้อความถูกทำเครื่องหมาย "(possibly unsent)" | ข้อความหายไปจาก 100 ข้อความล่าสุดของ LINE หลังจากเก็บไว้แล้ว จึงน่าจะถูกยกเลิกส่ง ข้อความที่บันทึกไว้ยังอยู่ |
| รูปภาพหรือไฟล์ถูกทำเครื่องหมาย "expired" หรือ "over 20 MiB" | LINE ไม่มีไฟล์นั้นแล้ว หรือเกินขีดจำกัดของไคลเอนต์นี้ ดาวน์โหลดไม่ได้ |
| คำเตือนว่าคลังอยู่ในรีโพ git | ตั้ง `archive_root` (หรือ `LINE_SKILL_ARCHIVE`) ไปยังโฟลเดอร์นอกรีโพ |
| ค้นหาชื่อแชตแล้วขึ้น "LINE request failed" | ต้นทางตั้งชื่อทุกแชตรวมถึงแชตที่ไม่ได้ใช้งานในคราวเดียว และถ้าล้มเหลวหนึ่งชุดก็ล้มทั้งหมด Claude จะสลับไปค้นเฉพาะแชตที่ใช้งานอยู่และแจ้งให้ทราบ แชตที่ไม่ได้ใช้งานค้นด้วยชื่อไม่ได้ ให้ใช้ ID เต็มแทน |
| ข้อความในกลุ่มแสดง ID ที่ถูกตัดแทนชื่อ | สมาชิกกลุ่มที่ไม่ใช่เพื่อนค้นหาเป็นรายชื่อผู้ติดต่อไม่ได้ การซิงก์จะอ่านชื่อจากข้อความแชตแทนและแคชไว้ ถ้ายังไม่มีชื่อ แปลว่าคนนั้นไม่ได้พิมพ์ใน 100 ข้อความล่าสุด |
| ส่งข้อความหาบุคคลหนึ่งล้มเหลวทุกครั้งพร้อมข้อความ "LINE request failed" | บั๊กต้นทาง: แชตส่วนตัวบางรายที่ LINE ปฏิเสธเวอร์ชันการเข้ารหัสที่ CLI ใช้ (ข้อผิดพลาด 10051 / 86 "e2ee or version mismatch") ข้อความไม่ได้ถูกส่ง Claude จะแจ้งตามจริงและไม่ลองส่งซ้ำ ให้ส่งจากแอป LINE แทน การอ่านแชตนั้นยังใช้ได้ตามปกติ |
| `chats --search` หรือการค้นหาชื่อสมาชิกกลุ่มล้มเหลวพร้อม "LINE request failed" | บั๊กต้นทาง: ถ้าในชุดข้อมูลมีบัญชีที่ถูกลบหรือสมาชิกที่ไม่ใช่เพื่อน การค้นหารายชื่อของ LINE จะล้มเหลวทั้งชุด มีวิธีแก้ลัดไว้แล้ว (ค้นเฉพาะแชตที่ยังใช้งาน และอ่านชื่อจากข้อความแชต) ดูสองแถวด้านบน |
| ติดตั้งบน Windows ใน Git Bash แล้วเกิดข้อผิดพลาด `tar` | GNU tar ของ Git อ่านเส้นทาง `C:` ไม่ได้ ตอนนี้ตัวติดตั้งจะวาง System32 ของ Windows ไว้หน้าสุดของ PATH ถ้าติดตั้งเอง ให้รันจาก PowerShell |
