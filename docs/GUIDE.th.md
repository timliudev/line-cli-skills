> โปรเจกต์ที่ไม่เป็นทางการ ไม่มีความเกี่ยวข้องกับ และไม่ได้รับการรับรองจาก LINE Corporation / LY Corporation ใช้ไคลเอนต์ kongesque/line-cli ที่ไม่เป็นทางการ ซึ่งอาจเสี่ยงทำให้บัญชี LINE ของคุณถูกระงับ ดูรายละเอียดใน README

คุณส่วนใหญ่เพียงพูดคุยกับ Claude Code ด้วยภาษาของคุณเอง คู่มือนี้อธิบายว่าเกิดอะไรขึ้นเบื้องหลัง Claude จะถามอะไรคุณบ้าง และแก้ปัญหาอย่างไร

## การติดตั้ง

เพิ่ม marketplace และติดตั้งปลั๊กอิน:

**วิธี A (แนะนำ): พิมพ์ภายใน Claude Code** เปิด Claude Code (แบบเทอร์มินัล หรือแท็บ Code ในแอป Claude บนเดสก์ท็อป) แล้วพิมพ์ในช่องแชทของมันทีละบรรทัด กด Enter หลังแต่ละบรรทัด:

```text
/plugin marketplace add timliudev/line-cli-skills
/plugin install line-cli@line-cli-skills
/plugin install media-digest@line-cli-skills
```

จากนั้นเริ่มเซสชัน Claude Code ใหม่ เพื่อให้ปลั๊กอินโหลด

**วิธี B: จากเทอร์มินัล** หากติดตั้งคำสั่ง `claude` แล้ว ให้เปิด PowerShell, Terminal หรือ bash แล้วรัน:

```bash
claude plugin marketplace add timliudev/line-cli-skills
claude plugin install line-cli@line-cli-skills
claude plugin install media-digest@line-cli-skills
```

**สำคัญ:** บรรทัดที่ขึ้นต้นด้วย `/` **ไม่ใช่**คำสั่งเทอร์มินัล หากพิมพ์ใน PowerShell, Terminal หรือ bash จะขึ้น "'/plugin' is not recognized" ใช้ได้เฉพาะภายใน Claude Code เท่านั้น ในเทอร์มินัลให้ใช้ `claude plugin ...` ของวิธี B

**วิธี C: เอเจนต์อื่น (Codex, Gemini CLI, Cursor, Copilot, OpenCode…)** ทั้งสองสกิลใช้รูปแบบเปิด [Agent Skills](https://agentskills.io) เอเจนต์ใดที่รองรับก็ใช้ได้ รันในเทอร์มินัล (ต้องมี Node.js):

```bash
npx skills add timliudev/line-cli-skills
```

- โปรแกรมจะพบทั้งสองสกิล (`line-cli`, `media-digest`) ถามว่าจะติดตั้งให้เอเจนต์ใด แล้วติดตั้งไว้ใน `.agents/skills/` (พร้อมลิงก์ไปยังโฟลเดอร์สกิลของแต่ละเอเจนต์ สำหรับ Claude Code คือ `.claude/skills/`)
- ขอบเขต: ค่าเริ่มต้นติดตั้งเฉพาะ**โฟลเดอร์โปรเจกต์ปัจจุบัน** ใส่ `-g` (`npx skills add -g timliudev/line-cli-skills`) เพื่อติดตั้งให้**ทุกโปรเจกต์** (`~/.agents/skills/`)
- อัปเดตภายหลังด้วย `npx skills update`
- **อย่าติดตั้งสกิลเดียวกันสองวิธีในเครื่องเดียว** หากใช้วิธี A หรือ B แล้วติดตั้งด้วยวิธี C อีก Claude Code จะเห็นสกิล `line-cli` ซ้ำสองตัว ให้เลือกทางเดียว หากจะเปลี่ยนวิธี ให้ลบอีกทางก่อน (`claude plugin uninstall line-cli@line-cli-skills` หรือ `npx skills remove line-cli`)

- `line-cli` สำหรับ LINE `media-digest` เป็นตัวเลือกเพิ่มเติม ใช้ได้กับไฟล์วิดีโอหรือเสียงทุกไฟล์ ติดตั้งหากคุณต้องการให้ Claude เข้าใจวิดีโอและข้อความเสียงของ LINE
- คุณต้องมี Python 3.11 ขึ้นไป หากระบบหา `python` ไม่พบ Claude จะลอง `python3` หรือ `py -3`
- โปรแกรม `line` จาก kongesque/line-cli ติดตั้งแยกต่างหาก คุณไม่ต้องทำเอง: ครั้งแรกที่ใช้ LINE Claude จะอธิบายว่าจะติดตั้งอะไร และถามคุณก่อน (ดูหัวข้อถัดไป)

## การตั้งค่าครั้งแรกและการเข้าสู่ระบบ

เมื่อคุณถามเรื่อง LINE เป็นครั้งแรก Claude จะตรวจสอบและพาคุณผ่านสิ่งที่ยังขาดอยู่ คุณจะถูกถามก่อนทุกขั้นตอน

1. **ติดตั้ง `line`** Claude จะบอกด้วยภาษาธรรมดาว่าจะดาวน์โหลด LINE CLI จากหน้า GitHub ทางการ นำไปไว้ในโฟลเดอร์ผู้ใช้ของคุณ (ไม่ต้องมีสิทธิ์ผู้ดูแลระบบ) และตรวจว่าไฟล์ไม่ถูกแก้ไข จะยังไม่มีอะไรเกิดขึ้นจนกว่าคุณจะตอบว่าใช่
   - Windows: ตัวติดตั้ง PowerShell ทางการ ไปยัง `%LOCALAPPDATA%\line-cli\bin`
   - macOS: Homebrew (`brew install kongesque/tap/line-cli`) หากคุณมี มิฉะนั้นใช้ตัวติดตั้ง shell ทางการ ไปยัง `~/.local/bin`
   - Linux: ตัวติดตั้ง shell ทางการ ไปยัง `~/.local/bin`
   - สคริปต์ตัวติดตั้งและโปรแกรมถูกกำหนดให้เป็นรีลีสเฉพาะที่ทดสอบแล้ว (v0.4.0) และตรวจสอบด้วย checksum (Homebrew จะติดตั้งรีลีสปัจจุบันของ tap จึงตรึงเวอร์ชันไม่ได้) ใช้งานได้ทันทีโดยไม่ต้องเปิดเทอร์มินัลใหม่
   - บนเดสก์ท็อป Linux อาจยังไม่มีแพ็กเกจ system keyring Claude จะแสดงคำสั่ง `sudo` ให้ และคุณเป็นคนรันเอง Claude จะไม่ใช้ `sudo` เด็ดขาด
2. **เข้าสู่ระบบ** Claude จะเตือนก่อน: **การเข้าสู่ระบบจะทำให้คุณออกจากระบบส่วนขยาย LINE สำหรับ Chrome** เพราะ LINE อนุญาตให้มีเซสชันแบบนี้ได้ทีละหนึ่งเซสชัน เมื่อคุณตอบตกลง หน้าต่างเทอร์มินัลใหม่จะเปิดขึ้น สแกน QR code ด้วย LINE บนโทรศัพท์ หรือเข้าสู่ระบบด้วยอีเมลและรหัสผ่านที่พิมพ์ในหน้าต่างนั้น Claude จะไม่เห็นรหัสผ่านของคุณ หน้าต่างล็อกอินจะปิดเองใน 3 วินาทีหลังสำเร็จ หากล้มเหลวหน้าต่างจะค้างไว้พร้อมข้อความแสดงข้อผิดพลาดจนกว่าคุณจะกด Enter ระบบจะรอได้สูงสุดห้านาทีและยืนยันด้วยชื่อบัญชีของคุณ หากเปิดหน้าต่างไม่ได้ (เช่น ผ่าน SSH) Claude จะให้คำสั่งเดียวให้คุณรันเอง
3. **เสร็จแล้ว** เซสชันจะถูกเก็บในที่เก็บข้อมูลที่ปลอดภัยของระบบปฏิบัติการ และต่ออายุตัวเองประมาณทุกสัปดาห์ ปกติคุณจึงเข้าสู่ระบบเพียงครั้งเดียว ต้องเข้าสู่ระบบอีกครั้งเฉพาะเมื่อ LINE ทำให้เซสชันออกจากระบบ

ไคลเอนต์ที่ไม่เป็นทางการมีความเสี่ยงต่อบัญชีของคุณ (ดูใน README) การใช้บัญชีสำรองจึงเป็นทางเลือกที่ฉลาด

## การใช้งานประจำวัน

เพียงพิมพ์ถาม เช่น "กลุ่ม Family พูดอะไรวันนี้บ้าง?" หรือ "มีข้อความใหม่จาก Anna ไหม?"

- **ค้นหาแชต** Claude จะค้นชื่อและใช้ ID แชตจริง หากมีหลายแชตตรงกัน (เช่น "Anna" ที่เป็นเพื่อน และ "Anna" ที่เป็นกลุ่ม) Claude จะแสดงรายการและถามว่าต้องการแชตไหน มันไม่เดาเอง
- **การอ่าน** Claude อ่านข้อความล่าสุด (ค่าเริ่มต้น 20 ข้อความ สูงสุดไม่เกิน 100 ข้อความล่าสุดต่อแชต ซึ่งเป็นขีดจำกัดของไคลเอนต์นี้ตามที่ LINE กำหนด) แล้วสรุปเป็นภาษาของคุณ รูปภาพ วิดีโอ ข้อความเสียง และไฟล์จะปรากฏเป็นไฟล์แนบที่คุณขอให้เปิดได้ สติกเกอร์แสดงไม่ได้ การอ่านไม่ทำให้ข้อความถูกทำเครื่องหมายว่าอ่านแล้ว
- **ใครตอบกลับหรือกดรีแอคชัน** ถามได้เลย เช่น "ข้อความ 'ทั้ง 33 รายการจัดการเรียบร้อยแล้ว' ของฉัน มีใครตอบบ้าง" Claude จะซิงก์ก่อน หาข้อความนั้นในคลังเก็บในเครื่อง แล้วแสดงคำตอบและรีแอคชันที่มี หาได้เฉพาะข้อความที่อยู่ในคลังเก็บแล้วเท่านั้น
- **ส่ง ตอบกลับด้วยรีแอ็กชัน และยกเลิก** การกระทำเหล่านี้ไปถึงคนอื่น จึงยืนยันทุกครั้ง Claude จะแสดงชื่อแชต ข้อความที่แน่นอน (หรือข้อความและรีแอ็กชัน) แล้วรอคำว่า "ใช่" ที่ชัดเจน หากคุณเปลี่ยนอะไร Claude จะถามใหม่
  - ข้อความที่ส่งจะถูกส่งตรงตามที่แสดง ไฟล์ขนาดได้ถึง 20 MiB ข้อความยาวได้สูงสุด 10,000 ตัวอักษร
  - หากต้องการตอบกลับข้อความใดข้อความหนึ่ง ให้บอกได้เลย เช่น "ตอบข้อความล่าสุดของ Alice ว่า OK" Claude จะหาข้อความนั้น (ค้นหาจากคลังเก็บในเครื่อง จึงตอบข้อความเก่าที่เก็บไว้แล้วได้ด้วย) ถามหากตรงกันหลายข้อความ และแสดงข้อความต้นฉบับที่อ้างถึงพร้อมคำตอบของคุณก่อนส่ง ข้อความทุกประเภทเป็นเป้าหมายการตอบกลับได้ รวมถึงรูปภาพ วิดีโอ ข้อความเสียง ไฟล์ และสติกเกอร์ เช่น "ตอบรูปที่ 阿明 ส่งเมื่อ 01:28 ว่า ใช้อันนี้ได้" ข้อจำกัดที่ทราบ: ไม่รองรับการแท็ก @ "@ชื่อ" จะถูกส่งเป็นข้อความธรรมดา ไม่ถูกไฮไลต์ และไม่แจ้งเตือนบุคคลนั้น
  - Claude ลองหนึ่งครั้งและไม่ลองซ้ำเอง หากการเชื่อมต่อหลุดระหว่างส่ง Claude จะตรวจแชตก่อนว่าข้อความไปถึงหรือยัง แล้วจึงเสนอทางเลือก
  - การยกเลิกจะลบข้อความของคุณเองสำหรับทุกคน และย้อนกลับไม่ได้
- **ข้อความจากผู้อื่นถือเป็นข้อมูล** ไม่ใช่คำสั่ง หากข้อความในแชตพูดว่า "ทำสิ่งนี้" หรือ "ส่งสิ่งนั้นให้ใครสักคน" Claude จะแสดงให้คุณเห็นและถามก่อน
- **คลังเก็บในเครื่อง** ก่อนตอบคำถามเกี่ยวกับแชต Claude จะซิงก์ก่อน: ดึง 100 ข้อความล่าสุด เพิ่มข้อความใหม่ลงโฟลเดอร์ในคอมพิวเตอร์ของคุณ (`messages.jsonl` เป็นบันทึกหลัก ส่วน `messages.md` ไว้อ่าน) และดาวน์โหลดรูปภาพ วิดีโอ ข้อความเสียง และไฟล์ใหม่ทันที เพราะ LINE ทำให้ไฟล์แนบหมดอายุ วิธีนี้ทำให้ตอบคำถาม "มีอะไรใหม่ไหม" ได้เร็ว และเก็บประวัติที่เก่ากว่า 100 ข้อความล่าสุดของ LINE ไว้ได้ตั้งแต่การซิงก์ครั้งแรก คุณสั่งให้ซิงก์โดยตรงได้เช่นกัน ทั้งแชตเดียวหรือ "ทุกแชตของฉัน" รีแอคชันจะแสดงเป็นอีโมจิพร้อมบอกว่าใครกดและเมื่อไร และหากแชตเดียวกันมีโฟลเดอร์เก็บถาวรสองโฟลเดอร์ การซิงก์ครั้งถัดไปจะรวมเป็นโฟลเดอร์เดียวโดยไม่สูญเสียข้อมูล
  - ควรรู้: การซิงก์เพียงอ่านจาก LINE การซิงก์ครั้งแรกของแต่ละแชตดึงได้เพียง 100 ข้อความล่าสุด หากระหว่างการซิงก์สองครั้งมีข้อความเข้ามาเกิน 100 ข้อความ Claude จะแจ้งว่ามีช่องว่าง ข้อความที่เก็บไว้แล้วแต่หายไปจาก 100 ข้อความล่าสุดของ LINE จะถูกเก็บไว้และทำเครื่องหมาย "(possibly unsent)" (อาจถูกยกเลิกส่ง) ซึ่งเป็นเพียงการคาดเดา ไม่ใช่ข้อสรุป
  - รีแอคชัน: ชุดมาตรฐานของ LINE 6 แบบ (ถูกใจ หัวใจ ขำ ตกใจ เศร้า โกรธ) แสดงเป็น emoji ส่วนรีแอคชันอีโมจิ LINE แบบอื่นแสดงเป็นรูปภาพ และเมื่อ Claude ดูแล้วจะบันทึกป้ายกำกับสั้น ๆ ไว้ การซิงก์จะเก็บรูปของอีโมจิแต่ละตัวที่ไม่ซ้ำกันเพียงครั้งเดียวในโฟลเดอร์ `_line_emoji` ที่ใช้ร่วมกันในคลังเก็บ (ใช้ร่วมทุกแชต คลังจึงโตตามจำนวนอีโมจิที่ไม่ซ้ำ ไม่ใช่ตามจำนวนครั้งที่ใช้) รูปแบบที่อยู่รูปภาพไม่เป็นทางการและอาจใช้ไม่ได้ในอนาคต (ดาวน์โหลดไม่สำเร็จจะลองใหม่อย่างมากสัปดาห์ละครั้ง) ปิดได้ด้วย `download.line_emoji = false` ข้อความสติกเกอร์จะแสดงเป็น "เนื้อหาที่ไม่รองรับ" เท่านั้น เพราะ line-cli ไม่บอกว่าเป็นสติกเกอร์ตัวไหน

## ไฟล์แนบและ media-digest

- **รูปภาพและ PDF** Claude เปิดไฟล์โดยตรงจากโฟลเดอร์คลังเก็บของแชตนั้น (ดาวน์โหลดไว้ตอนซิงก์ ไม่เกิน 20 MiB)
- **วิดีโอ** เมื่อมี `media-digest` Claude จะตัดวิดีโอเป็นเฟรมสำคัญ (ตามการเปลี่ยนฉาก สูงสุด 24 เฟรมโดยค่าเริ่มต้น) และถอดเสียงพูด แล้วอ่านไฟล์ `digest.md` เดียวที่เรียงเฟรมและข้อความตามเวลา
- **ข้อความเสียงและไฟล์เสียง** Claude ถอดเสียงพร้อมเวลากำกับ
- หากไม่มี `media-digest` Claude จะบอกตำแหน่งของไฟล์ และแจ้งว่าการติดตั้งปลั๊กอินจะทำให้เข้าใจวิดีโอและเสียงได้
- บางอย่างอาจขาดหายหรือใช้ไม่ได้: ไฟล์แนบที่ LINE หมดอายุแล้ว ไฟล์ที่เกิน 20 MiB และสื่อที่เก็บอยู่หลังลิงก์ภายนอกไม่สามารถดาวน์โหลดได้
- ระหว่างซิงก์ ไฟล์แนบใหม่จะถูกดาวน์โหลดให้ (ไม่เกิน 20 MiB ต่อไฟล์ ทุกประเภทตามค่าเริ่มต้น) ลงโฟลเดอร์ `files` ของแชตนั้น รูปภาพและ PDF อ่านจากที่นั่นโดยตรง ส่วนวิดีโอและข้อความเสียงจะส่งต่อให้ `media-digest`

สิ่งที่ `media-digest` ต้องใช้ จะเสนอให้เมื่อคุณยินยอม พร้อมระบุขนาดการดาวน์โหลด:

| ต้องการ | เพื่อ | วิธีติดตั้ง |
| --- | --- | --- |
| ขึ้น "'/plugin' is not recognized" (หรือ command not found) ใน PowerShell/Terminal | `/plugin ...` เป็นคำสั่งของ Claude Code ไม่ใช่คำสั่งเทอร์มินัล ให้พิมพ์ในช่องแชทของ Claude Code หรือในเทอร์มินัลใช้ `claude plugin marketplace add ...` / `claude plugin install ...` (ดูส่วนติดตั้ง) |
| ffmpeg | เฟรมวิดีโอ การจัดการเสียง | `winget install --id Gyan.FFmpeg -e` (Windows), `brew install ffmpeg` (macOS), `sudo apt install ffmpeg` (Linux, คุณรันเอง) |
| uv | ตัวถอดเสียงในเครื่องค่าเริ่มต้น | winget, brew หรือตัวติดตั้งทางการ |
| เอนจิน speech-to-text | บทถอดเสียง | `faster-whisper` ในเครื่องโดยค่าเริ่มต้น (ติดตั้งเองเมื่อใช้ครั้งแรก โมเดลประมาณ 1.6 GB ดาวน์โหลดครั้งเดียว) ทางเลือกอื่นอยู่ด้านล่าง |

หากไม่มี ffmpeg คุณยังได้รูปภาพและ PDF หากไม่มีเอนจิน speech-to-text คุณยังได้เฟรมสำคัญของวิดีโอ

Claude จะรัน `digest.py FILE... --out OUTDIR` จากโฟลเดอร์ `skills/media-digest/scripts` ของปลั๊กอินให้คุณ ตัวเลือกที่มีประโยชน์: `--lang zh` (ภาษาของเสียงพูด ค่าเริ่มต้นคือตรวจจับอัตโนมัติ), `--max-frames 24`, `--no-asr` (เฉพาะเฟรม), `--force` (ทำใหม่) ผลลัพธ์คือ `OUTDIR/digest.md` และ `digest.json` ผลลัพธ์จะถูกเก็บในแคช และไฟล์ที่ไม่มีบทถอดเสียงจะถูกลองใหม่อัตโนมัติเมื่อติดตั้งเอนจินแล้ว

## ส่งหลายแชต เก็บถาวรแบบสด และการแจ้งเตือน

- **ส่งข้อความเดียวไปหลายแชต** เช่น พูดว่า "ส่งประกาศนี้ให้ทุกคนในรายชื่อของฉัน" Claude จะเขียนรายชื่อและ**ทดลองก่อน** (แปลงทุกชื่อเป็นแชต ไม่ส่งอะไรเลย) แล้วแสดงผู้รับทุกคนและข้อความตามจริงให้คุณดู ใช้ได้เฉพาะชื่อที่ตรงกันทั้งหมดหรือ ID เต็ม ชื่อที่ตรงบางส่วนหรือซ้ำกันหลายแชตจะถามคุณ ไม่เดาเอง และถ้าการค้นหาชื่อของ LINE ตรวจสอบได้ไม่ครบ Claude จะขอ ID แชตเต็มแทน หลังคุณตอบตกลงอย่างชัดเจน จึงส่งทีละแชต เว้นช่วงสองสามวินาที หยุดทันทีที่ล้มเหลวครั้งแรก ไม่ลองซ้ำ และบอกว่าใครได้รับ ใครส่งไม่สำเร็จ และใครยังไม่ได้ส่ง การส่งหลายแชตที่ล้มเหลวจะไม่ถูกรันซ้ำอัตโนมัติ (คนที่ได้รับไปแล้วจะได้รับสองครั้ง) Claude จะเสนอส่งให้คนที่เหลือก็ต่อเมื่อคุณบอกเท่านั้น การส่งไปหลายแชตพร้อมกันอาจทำให้บัญชีถูกจำกัด จึงควรทำรายชื่อให้สั้น
- **อาร์ไคฟ์แบบสด** `watch.py` ทำให้อาร์ไคฟ์ทันสมัยอยู่เบื้องหลัง: คอยฟังข้อความใหม่ บันทึกทันทีที่มาถึง (ไฟล์แนบตามมาในไม่กี่วินาที) ซิงก์ตามให้ทันเมื่อ LINE แจ้งว่าพลาดเหตุการณ์ และเริ่มใหม่เองเมื่อการเชื่อมต่อหลุด (ถ้าล้มเหลวเร็วติดกัน 10 ครั้งจะเลิกลอง เพื่อไม่ให้วนซ้ำไม่จบ) รัน `line watch` ได้ครั้งละหนึ่งตัวเท่านั้น ถ้ามีตัวอื่นรันอยู่ `watch.py` จะแจ้งแล้วหยุด กด Ctrl-C เพื่อหยุดอย่างเรียบร้อย บน Windows รันด้วย `pythonw` หรือให้ Task Scheduler เริ่มตอนเข้าสู่ระบบ คำสั่งอยู่ใน `references/watch.md` ของสกิล Claude จะแสดงให้คุณดูเท่านั้น ไม่สร้างงานตั้งเวลาเอง โดยค่าเริ่มต้นจะเก็บเฉพาะแชตที่มีโฟลเดอร์อาร์ไคฟ์อยู่แล้ว หรือแชตที่คุณระบุไว้ใน `[watch] archive_chats` (หรือส่ง `--archive`) ข้อความของแชตอื่น เช่น แชตส่วนตัวที่คุณไม่เคยซิงก์ จะถูกเมินและไม่ถูกบันทึกหรือเขียนลงล็อก `--archive-all` จะเก็บทุกแชตและปิดไว้เป็นค่าเริ่มต้น ใช้เมื่อคุณสั่งอย่างชัดเจนเท่านั้น ข้อความตัวอักษรธรรมดาจะถูกบันทึกโดยไม่ติดต่อ LINE เลย จึงไม่กระทบการส่งของคุณ เฉพาะตอนที่ `watch.py` ซิงก์เต็มรูปแบบ (ตอนเริ่ม หลังการซิงก์ซ้ำ การดาวน์โหลดไฟล์แนบ หรือการหาชื่อที่ไม่รู้จัก) เท่านั้นที่การส่งอาจถูกปฏิเสธว่า "another line command is using the session" ซึ่งหมายความว่าข้อความ**ยังไม่ถูกส่ง** รอสักครู่ แล้ว Claude จะส่งอีกครั้งหลังจากคุณยืนยัน
- **ช่องว่าง (gap)** LINE ส่งกลับเฉพาะ 100 ข้อความล่าสุด และไคลเอนต์นี้เลื่อนย้อนหลังไม่ได้ ถ้ามีข้อความเข้ามาเกิน 100 รายการระหว่างซิงก์สองครั้ง ข้อความตรงกลางจะหายถาวร ตอนนี้การซิงก์จะบอกช่วงเวลาที่หายไป (`gap`) วิธีหลีกเลี่ยงคือซิงก์ให้ถี่ขึ้นหรือรัน `watch.py` ทางเลือกถ้าไม่อยากมีโปรเซสทำงานตลอด: ให้ Windows Task Scheduler รัน `sync.py --all` ทุก 15 นาที (คำสั่ง `schtasks` อยู่ใน `references/watch.md`)
- **การแจ้งเตือน VIP** ใส่แชตสำคัญไว้ที่ `[watch] vip_chats` ใน `config.toml` (ชื่อหรือ ID แชตเต็ม) หรือใส่ `--vip` ให้ `watch.py` ระหว่างที่รันอยู่ ข้อความใหม่ที่เข้ามาในแชตเหล่านั้นจะแสดงการแจ้งเตือน Windows พร้อมชื่อแชต ผู้ส่ง และตัวอย่างสั้นๆ (ระบบอื่นหรือเมื่อแจ้งเตือนไม่สำเร็จจะเขียนบันทึกหนึ่งบรรทัดที่มีเพียงชื่อแชตและผู้ส่ง ไม่มีเนื้อหาข้อความ) ข้อความที่คุณส่งเองและข้อความเก่าที่ค้างอยู่จะไม่ทำให้เกิดการแจ้งเตือน แชต VIP ที่ไม่ได้เก็บถาวรก็ยังแจ้งเตือน แต่จะไม่มีอะไรถูกเขียนลงดิสก์ ตัวอย่างข้อความจะแสดงเนื้อหาแชตบนหน้าจอ

## การตั้งค่า

ทุกอย่างใช้งานได้โดยไม่ต้องตั้งค่า มีไฟล์ `config.toml` แบบไม่บังคับอยู่สองไฟล์ (แต่ละสกิลบันทึกรายละเอียดไว้ใน `references/`) ความลับจะไม่ถูกเก็บในไฟล์เหล่านี้ เก็บเพียง**ชื่อ**ของตัวแปรสภาพแวดล้อมเท่านั้น

**`line-cli`** (`%APPDATA%\line-skill\config.toml` บน Windows มิฉะนั้นคือ `~/.config/line-skill/config.toml`):

| คีย์ | ความหมาย |
| --- | --- |
| `line_path` | ใช้โปรแกรม `line` ที่ระบุ (เช่น fork หรือบิลด์ที่ตรึงเวอร์ชันไว้) |
| `archive_root` | ตำแหน่งที่เก็บคลัง (ตั้งผ่านตัวแปรสภาพแวดล้อม `LINE_SKILL_ARCHIVE` ได้เช่นกัน และมีลำดับความสำคัญสูงกว่า) ค่าเริ่มต้น: `%LOCALAPPDATA%\line-skill\archive` (Windows), `~/Library/Application Support/line-skill/archive` (macOS), `~/.local/share/line-skill/archive` (Linux) |
| `download.types`, `download.max_bytes` | ประเภทไฟล์แนบที่ดาวน์โหลดอัตโนมัติ (`image`, `video`, `audio`, `file`) และขีดจำกัดขนาดเป็นไบต์ (ค่าเริ่มต้น 20 MiB ซึ่งเป็นค่าสูงสุดที่ไคลเอนต์นี้ดึงได้) และ `download.line_emoji` (ค่าเริ่มต้น `true` เก็บรูปรีแอคชันอีโมจิ LINE ตัวละหนึ่งครั้ง) |
| `render.quiet_gap_days` | ใน `messages.md` จะแทรกบรรทัด "no messages for X days" เมื่อข้อความสองข้อความติดกันห่างกันเกินจำนวนวันนี้ (ค่าเริ่มต้น 3; `0` คือปิด) |
| `watch.vip_chats` | แชต (ชื่อหรือ ID เต็ม) ที่ `watch.py` จะแจ้งเตือนเมื่อมีข้อความใหม่ เช่น `["Alice", "Project Team"]` |
| `watch.archive_chats` | แชต (ชื่อหรือ ID เต็ม) ที่ `watch.py` เก็บถาวรได้ นอกเหนือจากแชตที่มีโฟลเดอร์อาร์ไคฟ์อยู่แล้ว แชตอื่นจะถูกเมิน |

**`media-digest`** (`%APPDATA%\media-digest\config.toml` บน Windows มิฉะนั้นคือ `~/.config/media-digest/config.toml` เขียนทับได้ด้วย `MEDIA_DIGEST_CONFIG`):

```toml
[asr]
order = ["faster_whisper", "whisper_cpp", "groq"]   # try these in order

[asr.routes]                                          # per speech language
zh = ["faster_whisper", "groq"]

[adapters.groq]                                       # a cloud service, used because it is listed above
preset = "groq"                                       # api_key_env = "GROQ_API_KEY" comes with the preset
```

- เอนจิน: `faster_whisper` (ในเครื่อง ค่าเริ่มต้น), `whisper_cpp` (ในเครื่อง ต้องมี `model_path`), `openai_compat` (preset ของ OpenAI, Groq, vLLM, Speaches หรือ URL ของคุณเอง) และ `command` (โปรแกรมใดก็ได้ที่คุณมี รวมถึงเซิร์ฟเวอร์ของคุณเอง)
- หากไม่มีไฟล์ ระบบจะใช้เฉพาะในเครื่อง เอนจินคลาวด์จะถูกใช้ก็ต่อเมื่อระบุไว้ใน `order` หรือ `routes`
- ส่งออก API key ในเชลล์ที่เปิด Claude Code เช่น `export GROQ_API_KEY=...` และอย่าวางคีย์ลงในแชตเด็ดขาด
- เส้นทางตามภาษาจะมีผลเมื่อคุณระบุภาษา (`--lang zh`) ไม่มีผลเมื่อเป็น `auto`
- เอกสารอ้างอิงฉบับเต็ม: ไฟล์ `references/config.md`, `references/adapters.md` และ `references/install.md` ของปลั๊กอิน `media-digest`

## ความเป็นส่วนตัว

- แชต ไฟล์แนบที่ดาวน์โหลด และ digest ของคุณเป็นการสนทนาส่วนตัว เก็บไว้ในเครื่องของคุณ ไม่เคยอยู่ในโฟลเดอร์ปลั๊กอิน ห้าม commit หรือเผยแพร่ และเก็บให้พ้นจากรีโป git ใดๆ
- คลังเก็บคือโฟลเดอร์บทสนทนาส่วนตัวในเครื่องของคุณ (ค่าเริ่มต้นอยู่ในโปรไฟล์ผู้ใช้ ไม่เคยอยู่ในไดเรกทอรีของปลั๊กอิน) หากตำแหน่งคลังอยู่ในรีโพ git Claude จะเตือน ให้ย้ายออก และห้าม commit หรือเผยแพร่เด็ดขาด
- Claude จะไม่ส่งเนื้อหาแชตไปยังบริการอื่น การถอดเสียงทำในเครื่องเว้นแต่คุณตั้งค่าเอนจินคลาวด์ Claude จะบอกว่าบริการใดจะได้รับเสียง และถามก่อนอัปโหลดครั้งแรก
- Claude จะไม่ขอรหัสผ่าน LINE ของคุณในแชต และไม่อ่านเซสชันที่เก็บไว้
- การส่ง ตอบกลับด้วยรีแอ็กชัน และยกเลิก ต้องได้รับคำว่า "ใช่" อย่างชัดเจนจากคุณทุกครั้ง จะไม่มีการส่งอะไรในเบื้องหลัง
- ข้อความที่คุณอ่านอาจมีคำสั่งที่มุ่งถึง AI Claude จะถือว่าเป็นข้อความ ไม่ใช่คำสั่ง

## การแก้ปัญหา

ลองพิมพ์ให้ Claude ว่า "run the LINE doctor" ระบบจะรัน `setup.py --doctor` จากโฟลเดอร์ `skills/line-cli/scripts` ของปลั๊กอิน ซึ่งตรวจ Python โปรแกรม `line` และเวอร์ชัน การเข้าสู่ระบบ keyring (Linux) ไฟล์ตั้งค่า โฟลเดอร์คลังเก็บเขียนได้หรือไม่ และว่ามีการอัปเดตหรือไม่ พร้อมคำแนะนำเป็นภาษาธรรมดาสำหรับแต่ละรายการ ตรวจผลลัพธ์ก่อนวางในรายงานบั๊ก เพราะอาจมีพาธในเครื่องและชื่อบัญชีของคุณ

| อาการ | ควรทำอย่างไร |
| --- | --- |
| "line not found" | ให้ Claude รันการติดตั้งแบบมีคำแนะนำ หรือตรวจ `line_path` ในไฟล์ตั้งค่า |
