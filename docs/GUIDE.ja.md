ほとんどの場合、普段お使いの言語で Claude Code に話しかけるだけで操作できます。このガイドでは、裏側で何が起きるか、Claude が何を確認してくるか、問題の直し方を説明します。

## インストール

マーケットプレイスを追加し、プラグインをインストールします。

```
/plugin marketplace add timliudev/line-cli-skills
/plugin install line-cli@line-cli-skills
/plugin install media-digest@line-cli-skills
```

- `line-cli` は LINE 用です。`media-digest` は任意で、どの動画や音声ファイルにも使えます。LINE の動画やボイスメッセージを Claude に理解させたい場合にインストールしてください。
- Python 3.11 以上が必要です。システムで `python` が見つからない場合、Claude は `python3` または `py -3` を試します。
- kongesque/line-cli の `line` プログラムは別途インストールします。ご自身で行う必要はありません。初めて LINE を使うときに、Claude がインストール内容を説明し、先に確認を取ります（次のセクション）。

## 初回セットアップとログイン

初めて LINE について依頼すると、Claude が確認を行い、不足しているものを順に案内します。各手順の前に確認を取ります。

1. **`line` のインストール。** Claude は、LINE CLI を公式 GitHub ページからダウンロードし、ユーザー自身のフォルダに（管理者権限は不要）配置し、ファイルが改ざんされていないことを検証する、と平易に説明します。「はい」と答えるまで何も実行されません。
   - Windows：公式の PowerShell インストーラーで `%LOCALAPPDATA%\line-cli\bin` にインストールします。
   - macOS：Homebrew（`brew install kongesque/tap/line-cli`）があればそれを使い、なければ公式のシェルインストーラーで `~/.local/bin` にインストールします。
   - Linux：公式のシェルインストーラーで `~/.local/bin` にインストールします。
   - インストーラーとプログラムは、テスト済みの特定のリリース（v0.4.0）に固定され、チェックサムで検証されます。ターミナルを開き直さなくても、すぐに使えます。
   - Linux デスクトップでは、システムのキーリングパッケージが不足している場合があります。その場合、Claude が `sudo` コマンドを表示するので、ご自身で実行してください。Claude が `sudo` を使うことはありません。
2. **ログイン。** Claude は事前に警告します。**ログインすると LINE の Chrome 拡張機能からログアウトされます。** LINE は同時に1つのこうしたセッションしか許可しないためです。「はい」と答えた後、新しいターミナルウィンドウが開きます。スマートフォンの LINE で QR コードを読み取るか、そのウィンドウにメールアドレスとパスワードを入力してサインインします。Claude がパスワードを見ることはありません。最長5分待機し、アカウント名で確認します。ウィンドウを開けない場合（SSH 経由など）、Claude が実行すべきコマンドを1つ示します。
3. **完了。** セッションは OS の安全な保管領域に保存され、約1週間ごとに自動で更新されます。通常、ログインは1回で済みます。LINE 側でセッションが無効化された場合にのみ、再度ログインが必要です。

非公式クライアントはアカウントにリスクをもたらします（README を参照）。予備のアカウントを使うのが賢明です。

## 日常的な使い方

「今日 Family グループは何か言ってた？」「Anna から新しいメッセージはある？」のように、そのまま依頼してください。

- **トークの特定。** Claude は名前を検索し、実際のトーク ID を使います。複数のトークが一致する場合（友だちの「Anna」とグループの「Anna」など）は一覧を示して、どちらかを尋ねます。推測はしません。
- **閲覧。** Claude は最新のメッセージを読み（既定は20件。1トークあたり最大100件まで。これは本クライアントの LINE 側の制限です）、お使いの言語で要約します。写真、動画、ボイスメッセージ、ファイルは添付として表示され、開くよう依頼できます。スタンプは表示できません。閲覧してもメッセージは既読になりません。
- **送信、リアクション、送信取消。** これらは他の人に届くため、1件ずつ確認します。Claude はトーク名、正確な本文（またはメッセージとリアクション）を示し、明確な「はい」を待ちます。内容を変えた場合は、改めて確認します。
  - 送信するテキストは表示されたとおりに送られます。ファイルは最大20 MiB、メッセージは最大10,000文字です。
  - Claude は一度だけ試行し、自分の判断で再試行はしません。送信途中で接続が切れた場合は、何かを提案する前に、トークを確認してメッセージが届いたかどうかを調べます。
  - 送信取消は、自分のメッセージを全員の画面から削除します。取り消せません。
- **他の人のメッセージは、データとして扱われます。** トークのメッセージに「これを実行して」「あの人に送って」と書かれていても、Claude はそれをあなたに示して確認します。
- **ローカルアーカイブ。** トークについて答える前に、Claude はまず同期を行います。直近100件のメッセージを取得し、新しいものをお使いの PC 内のフォルダ（`messages.jsonl` が記録本体、`messages.md` が閲覧用）に追加し、新しい写真・動画・ボイスメッセージ・ファイルはすぐにダウンロードします。LINE 側で添付ファイルの期限が切れるためです。これにより「新着はある？」にすばやく答えられ、最初の同期以降は LINE の直近100件より古い履歴も残ります。1つのトーク、または「すべてのトーク」を指定して、直接同期を頼むこともできます。
  - 注意点：同期は LINE から読み取るだけです。トークの最初の同期で取得できるのは直近100件までです。2回の同期の間に100件を超えるメッセージが届くと、Claude は欠落があると伝えます。アーカイブ済みのメッセージが LINE の直近100件から消えた場合は、保持したうえで「(possibly unsent)」（送信取消された可能性）と表示します。これは推測であり、確定ではありません。

## 添付ファイルと media-digest

- **写真と PDF。** Claude はファイル（最大20 MiB）を一時フォルダにダウンロードし、そのまま内容を確認します。
- **動画。** `media-digest` を使うと、Claude は動画をキーフレームに分割し（シーンの切り替わりごと、既定で最大24枚）、音声を文字起こししたうえで、フレームと文字を時刻順に組み合わせた1つの `digest.md` を読みます。
- **ボイスメッセージと音声。** タイムスタンプ付きで文字起こしします。
- `media-digest` がない場合、Claude はファイルの場所を伝え、プラグインをインストールすると動画や音声を理解できるようになることを説明します。
- 取得できないものもあります。LINE 側で期限切れになった添付、20 MiB を超えるファイル、外部リンクの先にあるメディアです。
- 同期中に新しい添付ファイルを自動でダウンロードします（1件あたり最大20 MiB、既定ではすべての種類）。保存先はそのトークの `files` フォルダです。写真と PDF はそこから直接読み、動画とボイスメッセージは `media-digest` に渡します。

`media-digest` に必要なもの（同意を得て、ダウンロードサイズを示したうえで提案されます）：

| 必要なもの | 用途 | 導入方法 |
| --- | --- | --- |
| ffmpeg | 動画のフレーム、音声の処理 | `winget install --id Gyan.FFmpeg -e`（Windows）、`brew install ffmpeg`（macOS）、`sudo apt install ffmpeg`（Linux、ご自身で実行） |
| uv | 既定のローカル文字起こし | winget、brew、または公式インストーラー |
| 音声認識エンジン | 文字起こし | 既定はローカルの `faster-whisper`（初回使用時に自動でインストールされます。モデルは約1.6 GB で、初回のみダウンロードします）。代替は下記 |

ffmpeg がなくても画像と PDF は扱えます。音声認識エンジンがなくても、動画のキーフレームは得られます。

Claude は、プラグインの `skills/media-digest/scripts` フォルダから `digest.py FILE... --out OUTDIR` を実行します。主なオプションは `--lang zh`（音声の言語。既定は自動判定）、`--max-frames 24`、`--no-asr`（フレームのみ）、`--force`（やり直し）です。出力は `OUTDIR/digest.md` と `digest.json` です。結果はキャッシュされ、文字起こしがなかったファイルは、エンジンがインストールされると自動で再試行されます。

## 設定

設定しなくても動作します。任意の `config.toml` が2つあります（各スキルの詳細は `references/` に記載）。秘密情報は保存されず、環境変数の**名前**のみを記録します。

**`line-cli`**（Windows では `%APPDATA%\line-skill\config.toml`、それ以外では `~/.config/line-skill/config.toml`）：

| キー | 意味 |
| --- | --- |
| `line_path` | 特定の `line` プログラムを使用します（フォークや固定ビルドなど） |
| `archive_root` | アーカイブの保存先（環境変数 `LINE_SKILL_ARCHIVE` でも指定でき、そちらが優先されます）。既定：`%LOCALAPPDATA%\line-skill\archive`（Windows）、`~/Library/Application Support/line-skill/archive`（macOS）、`~/.local/share/line-skill/archive`（Linux） |
| `download.types`, `download.max_bytes` | 自動でダウンロードする添付の種類（`image`、`video`、`audio`、`file`）と、サイズ上限（バイト数。既定は20 MiB で、本クライアントが取得できる上限でもあります） |

**`media-digest`**（Windows では `%APPDATA%\media-digest\config.toml`、それ以外では `~/.config/media-digest/config.toml`。`MEDIA_DIGEST_CONFIG` で変更できます）：

```toml
[asr]
order = ["faster_whisper", "whisper_cpp", "groq"]   # try these in order

[asr.routes]                                          # per speech language
zh = ["faster_whisper", "groq"]

[adapters.groq]                                       # a cloud service, used because it is listed above
preset = "groq"                                       # api_key_env = "GROQ_API_KEY" comes with the preset
```

- エンジン：`faster_whisper`（ローカル、既定）、`whisper_cpp`（ローカル、`model_path` が必要）、`openai_compat`（OpenAI、Groq、vLLM、Speaches のプリセット、または独自の URL）、`command`（お持ちの任意のプログラム。独自のサーバーを含みます）。
- 設定ファイルがない場合、チェーンはローカルのみです。クラウドエンジンは `order` または `routes` に記載されている場合にのみ使われます。
- API キーは Claude Code を起動するシェルで設定してください（例：`export GROQ_API_KEY=...`）。キーをチャットに貼り付けないでください。
- 言語ごとのルートは、言語を指定した場合（`--lang zh`）に適用されます。`auto` の場合は適用されません。
- 完全なリファレンスは、`media-digest` プラグインの `references/config.md`、`references/adapters.md`、`references/install.md` にあります。

## プライバシー

- トーク、ダウンロードした添付ファイル、ダイジェストは非公開の会話です。お使いのマシンに保存され、プラグインのディレクトリには置かれません。絶対にコミット・公開せず、どの git リポジトリにも入れないでください。
- アーカイブは、お使いの PC 上にある非公開の会話のフォルダです（既定ではユーザープロファイル内で、プラグインのディレクトリには置きません）。保存先が git リポジトリ内にある場合は Claude が警告します。場所を移し、コミットや公開は絶対にしないでください。
- Claude はトークの内容を他のサービスに送信しません。文字起こしは、クラウドエンジンを設定しない限りローカルで行われます。クラウドエンジンを使う場合、Claude は音声を受け取るサービスを伝え、最初のアップロードの前に確認します。
- Claude がチャットで LINE のパスワードを尋ねることはなく、保存されたセッションを読むこともありません。
- 送信、リアクション、送信取消には必ず明示的な「はい」が必要です。バックグラウンドで送信されることはありません。
- 読んだメッセージには、AI に向けた指示が含まれている場合があります。Claude はそれを命令ではなく、単なるテキストとして扱います。

## トラブルシューティング

Claude に「LINE のドクターを実行して」と依頼してください。プラグインの `skills/line-cli/scripts` フォルダから `setup.py --doctor` が実行され、Python、`line` プログラムとそのバージョン、ログイン状態、キーリング（Linux）、設定ファイル、更新の有無を確認して、各項目について平易な対処法を表示します。バグ報告に貼り付ける前に出力を確認してください。ローカルのパスやアカウント名が含まれる場合があります。

| 症状 | 対処 |
| --- | --- |
| "line not found" | Claude にガイド付きインストールを実行してもらうか、設定の `line_path` を確認してください |
| "not logged in" | Claude にログインを依頼してください。Chrome 拡張機能からもログアウトされることに注意してください |
| ログインウィンドウが開かなかった | ターミナルで `line login` をご自身で実行し、その後 Claude に再確認を依頼してください |
| Linux：キーリングがない、またはロックされている | Claude が表示するパッケージ（`libsecret-tools`、`gnome-keyring`）をインストールし、キーリングのロックを解除してください。サーバーの場合は `references/setup.md` のヘッドレスオプションを参照してください |
| "busy" | 別の `line` コマンドが実行中です。少し待ってください（読み取りは自動で再試行されます） |
| フレームはあるが文字起こしがない | 使用可能な音声認識エンジンがありません。Claude に一覧の表示と設定を依頼してください |
| "needs ffmpeg" | ffmpeg をインストール（上記参照）してから、再度実行してください |
| クラウドサービスで長い録音の文字起こしが失敗する | 25 MB を超える音声はまだ分割できません。ローカルエンジンを使ってください |
| メッセージが送信されたか不明 | Claude がまずトークを確認します。あなたの「はい」なしに再送することはありません |
| Claude が「欠落」を知らせる | 前回の同期以降に100件を超えるメッセージが届いたため、抜けた分は取り戻せません。同期をこまめに行ってください |
| メッセージに "(possibly unsent)" と表示される | アーカイブ後に LINE の直近100件から消えたため、送信取消された可能性が高いです。保存済みの本文は残ります |
| 写真やファイルに "expired" や "over 20 MiB" と表示される | LINE 側にもう存在しないか、本クライアントの上限を超えているため、ダウンロードできません |
| アーカイブが git リポジトリ内にあるという警告 | `archive_root`（または `LINE_SKILL_ARCHIVE`）をリポジトリの外のフォルダに設定してください |
| トーク名の検索が "LINE request failed" で失敗する | 上流は非アクティブも含む全トークの名前を一括取得し、1件の失敗で全体が止まります。Claude はアクティブなトークから検索する方式に切り替えて知らせます。非アクティブなトークは名前では見つからないため、完全な ID を使ってください |
| グループのメッセージが名前でなく省略された ID で表示される | 友だちでないグループメンバーは連絡先として照会できません。同期ではトークのテキストから名前を読み取りキャッシュします。それでも名前が出ない場合、その人は直近100件で発言していません |
| 特定の相手への送信が毎回「LINE request failed」で失敗する | 上流のバグです。一部の1対1トークでは、CLI が使う暗号化バージョンを LINE が拒否します（エラー 10051／86「e2ee or version mismatch」）。メッセージは送信されておらず、Claude はその旨を伝え、再試行しません。LINE アプリから送ってください。そのトークの読み取りは問題ありません |
| `chats --search` やグループメンバー名の取得が「LINE request failed」で失敗する | 上流のバグです。同じバッチに削除済みアカウントや友だちでないメンバーがいると、LINE の連絡先取得がバッチ全体で失敗します。回避済みです（アクティブなトークのみ検索、名前はトーク本文から取得）。上の2行を参照してください |
| Git Bash で Windows のインストールが `tar` エラーになる | Git 同梱の GNU tar は `C:` パスを読めません。インストール時は Windows 標準の System32 を PATH の先頭に置くようになりました。手動で行う場合は PowerShell から実行してください |
